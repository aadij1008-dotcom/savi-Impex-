# SAVI IMPEX website

A responsive single-page business website for SAVI IMPEX. The site is served from `index.html` using GitHub Pages.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment to finish. GitHub will show the website URL in Settings → Pages.

The enquiry form opens WhatsApp with the visitor's message; it does not store submissions or send email. Tailwind, Google Fonts and Font Awesome load from external CDNs.
